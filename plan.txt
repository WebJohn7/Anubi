# Plan: rebuild the anubi.io homepage (local study copy)

## Context
The goal is to rebuild https://anubi.io from scratch, with the same fonts, colors, layout and
animations, as a practice exercise. It stays **local only**: it is never deployed and never
presented as the user's own work, because it uses Anubi's renders, wordmark and client logos.
This phase covers the homepage only.
Decisions: match the original stack · homepage first · their images used locally · IT with an EN toggle.
Copy: keep their short headings, nav labels and tags. Write my own body paragraphs of the same
length and tone instead of copying theirs.

## Steps
1. **Video frames.** `npm i -D ffmpeg-static` in `site/`. Extract 2 fps frames of the
   video to `refs/frames/`. Review them for: hero load sequence, scribble draw-in, services
   cycling, the gallery transition between cards, the Explore strip, the Code particle behavior,
   and the footer wordmark arrival. Number the motions in `refs/notes.md`.
2. **Assets** (local only): download the hero/gallery project images (Sanity CDN URLs from the
   page HTML), client logo SVGs, and the logo + ANUBI wordmark SVGs into `site/public/media/`.
3. **Tokens + fonts:** `styles/tokens.css` (everything above) and `styles/globals.css` reset.
   Fonts go in `_app.tsx` as CSS variables `--font-ui`, `--font-display`, `--font-mono`.
4. **i18n:** `content/home.it.json` and `home.en.json`, `lib/locale.tsx` context + `useT()`. The
   footer IT/EN buttons switch the language and persist it in localStorage.
5. **Static layout:** one folder per section in `components/` (Header, Hero, Clients, Services,
   Featured, ExploreAll, Research, CodeSection, ContactCta, Footer), each `index.tsx` +
   `style.module.css`, in page order. Match each screenshot before adding any motion.
6. **Motion:**
   - `lib/smooth.ts`: Lenis driven by `gsap.ticker`, synced with `ScrollTrigger.update`.
   - Reveals: fade/translate with `--ease-out`. SVG scribbles draw in with stroke-dashoffset.
   - Keyframes: logoOpacityWave, nodeDrift, wordmark-arrive.
   - Services cycle and Featured pin/scrub via ScrollTrigger.
   - Header and button hovers.
   - `prefers-reduced-motion` turns all of it off.
7. **WebGL / canvas (OGL):**
   - Hero: textured planes on a ring with perspective, idle drift and mouse parallax.
   - Research: line-rendered ring sculpture, rotating, with a pause toggle.
   - Code: 2D canvas particle text that scatters and returns around the cursor.
   - Each has a static fallback when WebGL is missing or motion is reduced.
8. **Diff loop:** screenshot localhost:3000 at 1536 CSS px in Chrome, section by section.
   Compare against anubi1–8, write the differences in `refs/notes.md`, fix them, and repeat. Then
   a 390px mobile pass, approximated without references unless the user adds phone screenshots.
